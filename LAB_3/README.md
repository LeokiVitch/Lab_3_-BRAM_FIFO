# LAB_3 FIFO project

Vivado project for the BRAM FIFO lab. Open `LAB_3.xpr` in Vivado 2023.2 or newer. The project targets the Zybo Z7-10 (`xc7z010clg400-1`).

## Files

- `LAB_3.srcs/sources_1/new/sc_fifo.v` — FIFO RTL
- `LAB_3.srcs/sim_1/new/tb_sc_fifo.v` — testbench
- `tb_sc_fifo_behav.wcfg` — simulation waveform layout
- `generate_fifo_data.py` and `input_data.txt` — data-generation helper and sample input

Vivado run products, caches, and machine-specific paths are excluded from version control.
